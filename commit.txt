form-config.html - reescrito. El body ahora tiene tres zonas: navbar, tab-bar y content. Ya no hay .page wrapper ni el antiguo header.

form-config.css - el bloque .hdr fue reemplazado por .navbar + .nav-brand + .nav-analyze + .nav-url-input. Se anadieron .tab-bar, .tab, .tab--active, .tab--pinned y .tab-close. El .url-err ahora es un tooltip absoluto que flota bajo el input del navbar. El .content reemplaza a .page con max-width: 960px.

form-config.js - se anadio el estado de pestanas (_tabs, _activeId, _tabSeq, MAX_TABS = 8) y las funciones createFormTab, closeTab, activateTab, renderTabBar y saveActiveForm. analyzeForm() ahora crea una pestana antes de hacer el fetch, actualiza su estado al terminar y detecta si la URL ya esta abierta. render() ya no toca scrollIntoView ni variables globales de formulario activo.

form-config.js - tambien normaliza endpoints de Google Forms de forma mas robusta: extrae el ID publicado 1FAIpQL... desde el HTML/FB_PUBLIC_LOAD_DATA_ y construye /forms/d/e/.../formResponse, evitando URLs invalidas derivadas de forms.gle. Ademas expone el boton "Vista previa" y guarda el estado relevante con persistInspectorState().

form-config.js - la extraccion de opciones ahora lee los textos reales de opcion multiple, casillas, escala y dropdown desde la estructura interna del entry. Antes solo miraba indices limitados y podia caer en opciones genericas como "Opcion 1" y "Opcion 2".

Alcance de opciones: cubre los casos comunes de Google Forms publicos para opcion multiple, casillas, escala lineal y dropdown. La estructura FB_PUBLIC_LOAD_DATA_ no esta documentada oficialmente por Google, asi que quedan como casos especiales posibles: cuadriculas, opcion "Otro" con texto libre, carga de archivos, formularios privados y formularios con logica/secciones complejas.

form-db.js - loadSaved() ahora crea una pestana en estado ready con los datos del registro en lugar de llamar render() directamente, detecta si ya esta abierta y persiste el estado cuando carga desde biblioteca.

persistencia.js - nuevo archivo dedicado a persistir el estado del inspector en localStorage. Guarda pestanas listas, pestana activa, secuencia de pestanas y el valor del input de URL. Restaura ese estado al recargar form-config.html sin mezclarlo con la cache de vista previa.

forms-previsualizer/ - se agrego la vista previa personalizada del formulario. Construye los campos desde la configuracion analizada, envia a Google Forms con fetch no-cors y muestra estados de exito/error. Incluye un boton sutil "Limpiar cache" para borrar gfi:preview cuando haya datos viejos en localStorage.

EditorForms/ - nueva primera version del editor visual. Carga el formulario activo desde gfi:editor, muestra una lista de campos, una previsualizacion editable y un panel de propiedades. Permite cambiar texto visible, placeholder, render visual del campo, ancho y visibilidad sin modificar entry.ID ni endpoint. Puede guardar cambios y enviar la configuracion editada a la vista previa.

EditorForms/editor.js - el boton Guardar ahora sincroniza tambien gfi:preview, para que la previsualizacion use los cambios editados sin depender solo del boton Vista previa.

EditorForms/editor.js y forms-previsualizer/preview.js - la previsualizacion ahora escucha cambios en vivo desde el editor mediante localStorage/BroadcastChannel y reconstruye el formulario cuando se guarda. Al reconstruir, limpia el form anterior para evitar campos duplicados o listeners repetidos.

form-config.js - openPreview() ahora revisa si existe una configuracion editada para el formulario activo en gfi:editor y la usa antes de caer al formulario original. openEditor() ya no pisa una edicion existente del mismo formulario al abrir el editor de nuevo.

form-config.html/css/js - se agrego el boton "Editar" junto a "Guardar en biblioteca" y "Vista previa". openEditor() guarda el formulario activo en localStorage con la clave gfi:editor y abre EditorForms/index.html.

forms-previsualizer/preview.js - ahora respeta overrides visuales enviados por el editor: renderAs, width y placeholder. Esto permite, por ejemplo, renderizar una opcion multiple como dropdown sin cambiar el name/entry real enviado a Google Forms.

Comportamiento completo:

Pestana "Biblioteca" siempre fija a la izquierda, sin boton de cerrar
Cada URL analizada -> nueva pestana con el titulo del formulario
Si la misma URL ya esta abierta -> activa esa pestana y muestra toast
Cerrar pestana con X -> activa la adyacente o vuelve a Biblioteca
Cargar desde biblioteca -> abre pestana propia
Maximo 8 formularios abiertos simultaneamente
Recargar la pagina -> restaura pestanas listas, tab activo y URL escrita
Vista previa -> usa endpoint canonico y permite limpiar su cache local
Editor -> permite ajustar la presentacion visual del formulario y reenviarla a vista previa

EditorForms/ - se agrego el exportador completo. El editor ahora genera automaticamente HTML, CSS, JS de envio y JSON desde la configuracion editada actual. Cada bloque tiene boton Copiar y tambien existe "Copiar todo", que entrega el HTML junto con style/script listos para pegar. Los exports respetan labels, placeholders, renderAs, ancho, campos ocultos, endpoint, entry IDs y opciones reales.

EditorForms/ - el exportador ahora incluye "Descargar ZIP". Genera en el navegador un archivo .zip estandar con index.html, styles.css, script.js y config.json. WinRAR puede abrirlo normalmente.

EditorForms/ - el index.html del ZIP enlaza styles.css como archivo externo. El CSS embebido se mantiene solo en la accion "Copiar todo", no dentro del index.html descargado.

EditorForms/ - el CSS exportado ahora replica el estilo visual de la previsualizacion: fondo suave con radial/linear gradient, tarjeta blanca con sombra amplia, Playfair para el titulo, inputs/selects redondeados, opciones tipo cards, boton verde CTA y banners de exito/error con el mismo lenguaje visual.

EditorForms/ - el HTML/CSS exportado ahora replica tambien la estructura de la previsualizacion: shell de dos columnas, panel izquierdo oscuro con titulo/descripcion/stats y formulario en la columna derecha. El index exportado carga Inter y Playfair desde Google Fonts.

EditorForms/ - se ajusto el grid del CSS exportado para evitar que inputs de dos columnas se superpongan visualmente: mayor column-gap/row-gap y control de overflow por campo.

EditorForms/ - el area central del editor ahora usa pestanas: Diseno y Exportar. La informacion de exportacion ya no aparece debajo de la previsualizacion, sino dentro de su propia pestana.

EditorForms/ - se corrigio el CSS exportado para que los inputs no se vean cortados: se agrego box-sizing global y se elimino el recorte por overflow en cada campo.

EditorForms/ - se agrego la pestana "Panel lateral" para editar la zona informativa izquierda del formulario. Permite cambiar insignia, titulo, descripcion, instrucciones adicionales y ocultar/mostrar tarjetas de campos, tipos y endpoint. Estos ajustes se guardan en gfi:editor, viajan a gfi:preview, aparecen en la previsualizacion y se reflejan en el HTML/CSS/JSON exportado.

EditorForms/ - el panel lateral ahora usa elementos informativos multiples. Cada elemento puede tener icono, etiqueta, contenido y fuente personalizada o automatica (campos, tipos de campo, endpoint). Se pueden agregar y borrar elementos libremente, y la previsualizacion/exportacion renderizan exactamente esa lista.

EditorForms/ - se recupero el estilo verde de las tarjetas informativas del panel: fondo verde/azulado sutil e iconos verdes consistentes en editor, previsualizacion y exportado. Cada tarjeta editable ahora tiene boton de colapsar/expandir para trabajar con listas largas sin ocupar tanto espacio.

forms-previsualizer/ - se agrego boton "Exportar" en la barra superior de la vista previa. Copia la configuracion actual de gfi:preview a gfi:editor y abre EditorForms directamente en la pestana Exportar mediante ?tab=export.

shared/form-exporter.js - se movio la descarga ZIP a un exportador compartido. EditorForms y forms-previsualizer ahora cargan el mismo archivo y usan FormExporter para generar index.html, styles.css, script.js y config.json. El boton del previsualizer ahora descarga el ZIP directamente desde gfi:preview sin abrir el editor.

shared/form-exporter.js - se corrigio el render de exports en pantalla: faltaba la funcion summarizeTypes usada por los elementos automaticos del panel lateral. EditorForms ahora tambien tiene fallback local si el exportador compartido falla, evitando dejar HTML/CSS/JS/JSON vacios.
